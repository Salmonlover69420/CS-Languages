Understanding Algorithm Complexity

Big-O Notation

Big-O describes how the running timr of an algorithm grows with the input size n

Sorting

Simple sorts

Bubble sort and selection sort in O(n2)

Efficient sorts

Merge sort runs in O(n log2 n)
Quick sort is always O(n log n). Quick sort is O(n log n) on average but O(n2) in the worst case

Searching

A brute-force search over all subsets costs O(2n). FInding the maximum of an array is linear:
for (int i = 0; i < n; i++) {
   if (a[i] > max) max = a[i];
