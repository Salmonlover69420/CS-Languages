Glossary

HTTP
Protocol that carries requests and responses between browser and server.
URL
The address of a resource on the web.
DNS
System that translates domain names into IP addresses.
Web Server
Computer that stores web resources and answers requests.
Web Browser
Client program that sends requests and displays pages.
IP Address
Number that identifies a device on a network.
